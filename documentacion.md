# Documentación del Gestor de Tareas Premium

## ¿Qué es esta aplicación?
Esta es una aplicación web moderna ("Gestor de Tareas Premium") diseñada para ayudarte a organizar tu día a día de manera sencilla y visualmente agradable. A diferencia de listas simples, esta aplicación recuerda tus tareas incluso si cierras el navegador.

## Características Principales

### 1. Persistencia de Datos
La aplicación utiliza el **LocalStorage** de tu navegador. Esto significa que:
- Si agregas tareas y cierras la ventana, al volver a entrar **tus tareas seguirán ahí**.
- No necesitas crear una cuenta ni iniciar sesión; todo se guarda en tu dispositivo.

### 2. Exportación a JSON
Hemos incluido una función avanzada para usuarios técnicos o para quienes deseen hacer copias de seguridad de sus datos:
- El botón **"Ver JSON"** genera una representación de texto crudo de todas tus tareas.
- Puedes copiar este texto y guardarlo en un archivo `.json` o usarlo en otros programas.
- El formato incluye el ID único de la tarea, el texto, y su estado (completado o no).

### 3. Diseño Premium
- **Modo Oscuro**: Interfaz agradable a la vista, perfecta para trabajar de noche.
- **Micro-interacciones**: Animaciones suaves al agregar, completar o eliminar tareas.
- **Fondo Dinámico**: Esferas animadas que le dan vida a la aplicación sin distraer.

## Guía de Uso
1.  **Agregar Tarea**: Escribe en el campo de texto y presiona ENTER o el botón "+".
2.  **Completar**: Haz clic en el recuadro a la izquierda de la tarea.
3.  **Eliminar**: Pasa el mouse sobre una tarea y haz clic en el icono de basura.
4.  **Ver Datos de Respaldo**: Haz clic en "Ver JSON" y usa el botón "Copiar al portapapeles".

Disfruta organizando tu vida con estilo.
